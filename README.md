# CalSync

A modern scheduling app for busy professionals.

## Vision

Scheduling should be frictionless. CalSync eliminates the back-and-forth of finding meeting times by understanding your availability, preferences, and priorities.

## Features (Planned)

- **Smart Availability** - Connect your calendars, set your preferences
- **One-Click Booking** - Share a link, let others book time with you
- **Intelligent Reminders** - Reduce no-shows with smart notifications
- **Team Scheduling** - Coordinate across calendars effortlessly

## Tech Stack

- Frontend: React + TypeScript
- Backend: Node.js + Express
- Database: PostgreSQL
- Calendar Integration: Google Calendar, Outlook APIs
